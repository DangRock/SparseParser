FSEQ Sparser

This tool parses full FSEQ files into individual sparse FSEQ files for each controller. Use this tool if you're having problems transferring sequences to your remotes using FPP Connect (weak Wi-Fi, timeouts, etc.) and want to instead generate sparse FSEQ files for each controller to install in each controller.

Select the folder that contains your FSEQ files, select your xlights_networks.xml and choose the individual sequences, if necessary. Sparser will generate the sparse FSEQ files in a "sparse" folder inside the FSEQ folder in separate folders for each controller (by name and IP). You then copy the contents of each folder to an SD card and install in the remote device.

All processing is done on your local machine. No files are copied to the internet. Chrome/Edge is required.

This browser can't write to local folders. Please use Chrome or Edge on a desktop.
