FSEQ Sparser

This tool parses full FSEQ files into individual sparse FSEQ files for each target controller. It is meant to be used in conjunction with xLights if you rely on FPP Connect to transmit your sequences to each controller over Wi-Fi. Longer sequences and many channels results in large FSEQ files. Transfering those large files will often fail due to several factors (weak Wi-Fi, timeouts, or CPU limitations). This tool will parse the FSEQ files generated by xLights into controller-specific sparse FSEQ files. You can then then load those files to an SD card and install manually, or transfer them to each controller using the controllers web interface (ESPixelStick / WLED, for example).

Select the folder that contains your FSEQ files, select your xlights_networks.xml and choose the individual sequences, if necessary. Sparser will generate the sparse FSEQ files in a "Sparser" folder inside the FSEQ folder in separate folders for each controller (by name and IP). You then copy the contents of each folder to an SD card and install in the remote device.

All processing is done on your local machine. No files are copied to the internet. Chrome/Edge is required.

This browser can't write to local folders. Please use Chrome or Edge on a desktop.
